# EC04 - API CityLunch

## 📌 Description

API REST développée avec Symfony permettant de gérer :
- les utilisateurs (création, modification, suppression)
- les produits
- les sacs des livreurs (ajout / retrait de produits)
- consultation des données via endpoints JSON
